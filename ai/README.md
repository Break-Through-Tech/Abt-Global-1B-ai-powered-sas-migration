# AI Project Resources

This folder contains guidelines and resources for using AI throughout
the project.

## Contents

- `MODEL_GUIDE.md` — AI model recommendations and free-tier considerations
- `AI_CHECKLIST.md` — Checklist for using and validating AI-assisted work
- `prompts/` — Phase-specific prompts and AI workflows

## General AI Workflow

Generate  
→ Cross-reference  
→ Investigate disagreements  
→ Test against source/expected outputs  
→ Human review

## Core Principle

AI is an assistant, not the source of truth.

The original project logic, requirements, expected outputs, and human
review are our priority over AI-generated interpretations but we believe 
they are a great way to start and continue building our understanding.
